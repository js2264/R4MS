# R for Mass Spectrometry documentation

This repository provides documentation and teaching material focus on
the analysis of mass spectrometry data for proteomics and metabolomics
using the [R for Mass
Spectrometry](https://www.rformassspectrometry.org/) software
infrastructure.


Go to http://rformassspectrometry.github.io/book to browse the
material online.

This repository holds a [BiocBook](https://github.com/js2264/BiocBook) version
of the book, migrated from its bookdown sources
([rformassspectrometry/book](https://github.com/rformassspectrometry/book))
with `BiocBook::from_bookdown()`: see [MIGRATION.md](MIGRATION.md). It is
built, with a Docker image providing every dependency, for each Bioconductor
release.
